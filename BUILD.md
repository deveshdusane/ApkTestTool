# TestMate AI — Build Guide

For the developer producing v1+ builds for QA testers.

## Prerequisites (one-time)

- Node 18+ and npm 9+
- macOS for Mac builds (or for cross-building Windows from Mac via electron-builder's bundled Wine)
- Windows 10/11 for native Windows builds (optional)

## Initial checkout setup

```bash
cd electron-app
npm install        # installs electron, electron-builder, app-info-parser, unzipper
```

You should not need to install anything in `agent/` separately — `electron-app/node_modules` has everything the packaged app needs.

## Building

From `electron-app/`:

| Command | Output |
|---|---|
| `npm run build:mac` | Both Mac DMGs (arm64 + x64) in `dist/` |
| `npm run build:win` | Windows NSIS installer `.exe` in `dist/` |
| `npm run build`     | Whatever target matches your current OS |

First build takes 1–2 minutes (downloads Electron binaries ~100 MB per arch + electron-builder downloads Wine ~19 MB on first Mac→Win build, all cached for next time).

## Artifacts produced

```
electron-app/dist/
├── TestMate AI-1.0.0-arm64.dmg     (≈103 MB) — Mac, Apple Silicon
├── TestMate AI-1.0.0.dmg           (≈108 MB) — Mac, Intel
├── TestMate AI Setup 1.0.0.exe     (≈ 78 MB) — Windows installer
├── mac-arm64/                       # unpacked .app for arm64
├── mac/                             # unpacked .app for x64
└── win-unpacked/                    # unpacked .exe directory
```

## Project layout (relevant to builds)

```
TestMate_AI/
├── electron-app/
│   ├── main.js, preload.js, start-electron.js
│   ├── renderer/                    # UI
│   ├── package.json                 # build config lives here
│   └── build/
│       ├── icon.png                 # 1024×1024 master icon
│       └── icon.icns                # generated for Mac
├── agent/                           # Node-side QA engine
└── tools/
    ├── mac/                         # adb (macOS arm64 + x64)
    └── win/                         # adb.exe, aapt.exe, dlls (Windows x64)
```

The build config in `electron-app/package.json` ships **only the right platform's binaries** in each artifact — the Mac DMG won't waste space on Windows .exe files and vice versa.

## Bumping the version

Edit `version` in `electron-app/package.json`. The artifact filenames pick it up automatically.

## Updating the bundled ADB

### Mac
```bash
curl -L -o /tmp/pt.zip https://dl.google.com/android/repository/platform-tools-latest-darwin.zip
unzip /tmp/pt.zip -d /tmp/
cp /tmp/platform-tools/adb tools/mac/adb
chmod +x tools/mac/adb
```

### Windows
```bash
curl -L -o /tmp/pt.zip https://dl.google.com/android/repository/platform-tools-latest-windows.zip
unzip /tmp/pt.zip -d /tmp/
cp /tmp/platform-tools/{adb.exe,AdbWinApi.dll,AdbWinUsbApi.dll} tools/win/
```

## Replacing the icon

Drop a new 1024×1024 PNG at `electron-app/build/icon.png`. Then regenerate the Mac `.icns`:

```bash
mkdir -p /tmp/icon.iconset
for s in 16 32 64 128 256 512 1024; do
  sips -z $s $s electron-app/build/icon.png --out /tmp/icon.iconset/icon_${s}x${s}.png
  [ $s -le 512 ] && sips -z $((s*2)) $((s*2)) electron-app/build/icon.png \
    --out /tmp/icon.iconset/icon_${s}x${s}@2x.png
done
iconutil -c icns /tmp/icon.iconset -o electron-app/build/icon.icns
```

Windows `.ico` is auto-generated by electron-builder from `icon.png`.

## Code signing (production releases)

Currently **unsigned** — testers see Gatekeeper / SmartScreen warnings but can bypass.

For a signed release:

- **Mac**: need an Apple Developer ID Application certificate. Set `CSC_LINK` and `CSC_KEY_PASSWORD` env vars before build, then enable notarisation via `mac.notarize: true` and Apple ID env vars (see https://electron.build/code-signing).
- **Windows**: need an Authenticode cert (.pfx). Set `CSC_LINK` / `CSC_KEY_PASSWORD` same as Mac.

## Troubleshooting

| Symptom | Fix |
|---|---|
| `electron-builder` complains about Wine on Mac | First Win build downloads Wine 4.0.1 automatically — needs network. Retry. |
| Build fails with `Cannot find module 'unzipper'` | Run `npm install` inside `electron-app/` (not at repo root) |
| `tools/mac/adb` shows "killed" on Mac | macOS quarantined the binary — run `xattr -d com.apple.quarantine tools/mac/adb` |
| ADB can't see device on packaged Mac app | The bundled adb is at `Contents/Resources/tools/mac/adb` — make sure it's `chmod +x` before packaging |
| Build size unexpectedly grew | Check `tools/` for stray binaries from the wrong platform |
