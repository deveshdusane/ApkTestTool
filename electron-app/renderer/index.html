📡 Connect Wireless Device
1
Connect your device with a USB cable. Allow USB debugging if prompted.
2
TestMate will detect it, read the Wi-Fi IP, switch the device into wireless mode, and connect.
3
After "Connected", unplug the USB cable. Subsequent test sessions will use Wi-Fi automatically.
Looking for USB devices…
1
On the device: Settings → Developer Options → Wireless debugging. Tap "Pair device with pairing code".
2
Phone shows a pairing IP:port + 6-digit code. Enter them below. Also note the "IP & Port" shown on the main Wireless debugging screen — that's the connect port (different from the pair port).
Wireless ADB requires PC and phone to be on the same IP-reachable network. On office networks where IT does not grant Wi-Fi access for phones, the network type does not matter — only that both devices can see each other. Here are the realistic options:
⭐ Recommended Windows Mobile Hotspot (free, no extra hardware)
  1. Press Win+I to open Settings
  2. Go to Network & Internet → Mobile Hotspot
  3. Set Share over = Wi-Fi, note the Network name + password
  4. Toggle the hotspot ON
  5. On the phone, connect to the PC's hotspot Wi-Fi
  6. Come back to TestMate, use USB Bootstrap tab to switch device to Wi-Fi mode
After setup, the phone auto-connects to the hotspot every time it's on. TestMate auto-reconnects on app start.
Backup Phone's Mobile Hotspot (uses phone's cellular data)
  1. On phone: Settings → Connections / Network → Mobile Hotspot → ON
  2. Note the hotspot name + password
  3. On PC: connect to the phone's hotspot Wi-Fi
  4. Phone uses its own data, PC borrows it
  5. Use USB Bootstrap tab in TestMate
⚠ Some corporate PCs block connecting to non-corp Wi-Fi via IT policy. Try Windows Hotspot first.
Hardware Personal pocket Wi-Fi router (₹2–3K one-time)
  1. Buy a 4G/5G pocket router from Amazon
  2. Power it on, both PC and phone connect to it
  3. Independent of office Wi-Fi — most reliable for QA labs
Hardware Secondary USB Wi-Fi dongle on PC (₹400)
  1. Plug a USB Wi-Fi dongle into PC — adds a secondary Wi-Fi interface
  2. Primary NIC stays on office Wi-Fi (your internet)
  3. Secondary NIC connects to phone's hotspot (your ADB lane)
  4. Use USB Bootstrap tab in TestMate
Best of both worlds: office internet on primary, isolated test network on secondary.
Fallback Just use USB cable (always works)

Wireless is a convenience, not a requirement. TestMate works perfectly with a USB-connected device. In offices with strict IT controls, USB is often the most reliable option.

Reference: project_office_network_constraint memory — common Funcell tester scenario.
